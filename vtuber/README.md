**01번(약 25줄)만 다 같이 치고**, 02~08번은 01번을 복사한 뒤 `★` 표시된 부분(3~12줄)만 추가로 칩니다.

실행:  이 폴더에서  python 01_face_points.py

## 01. AI로 얼굴 점 478개 찍기 (기본 틀)
- 다 같이 한 줄씩 칩니다. 이 틀이 08번까지 계속 쓰입니다.
- 짚어 줄 줄은 세 군데입니다.
  - `create_from_options`: AI 모델을 불러오는 줄
  - `detect_for_video`: 사진을 AI에게 보여 주는 줄
  - `p.x * w`: AI는 좌표를 0~1 비율로 주므로, 화면 크기를 곱해야 픽셀이 됩니다.
- **AI 이야기**: 이 모델은 사람이 점을 찍어 둔 수많은 얼굴 사진으로 학습했어요. 인터넷 없이 내 노트북에서만 돌아갑니다.
- **실험: AI 속이기**
  - 손으로 가리기, 옆얼굴, 불 끄기, 휴대폰으로 만화 캐릭터 비춰 보기
  - 언제 점이 사라지나요? 왜 그럴까요?
  - 참고로 이 폴더의 `character.png`(만화 얼굴)는 이 AI가 얼굴로 인식하지 못합니다. 학습한 데이터가 사람 사진뿐이기 때문이에요.

## 02. 점에는 번호가 있다
- 1번은 코, 152번은 턱, 159/145번은 눈 위/아래, 13/14번은 입술 위/아래입니다.
- **미션: 번호 찾기 대결**. 리스트의 숫자를 바꿔 가며 "귀 옆 점", "눈썹 끝 점" 번호를 먼저 찾기

## 03. 입 벌림 수치
- `math.dist`는 두 점 사이 거리를 구합니다.
- **미션: 입 크게 벌리기 대회**
  - 먼저 `/ math.dist(pts[61], pts[291])` 부분을 빼고 실행해 봅니다. 그럼 카메라에 얼굴을 들이대는 사람이 이겨요.
  - "이거 공정해?" → 입 너비로 나눠야 거리와 상관없이 공정해진다는 걸 학생들이 스스로 발견하게 하세요.

## 04. 눈 깜빡임 감지
- 03과 똑같은 원리(높이 ÷ 너비)입니다. 학생이 먼저 말하게 해 보세요.
- **미션**
  - 기준값 `0.2`를 내 눈에 맞게 바꾸기
  - 윙크하면 "WINK!" 띄우기 (`and` → 조건 바꾸기)

## 05. 고개 기울기
- 두 눈 사이에 직각삼각형을 그립니다: 밑변 dx(파랑), 높이 dy(빨강), 빗변 = 눈을 잇는 선(노랑). `atan2(dy, dx)`가 밑변과 높이로 각도(노란 호)를 구합니다.
- 화면의 dx, dy 숫자를 계산기 `tan⁻¹(dy ÷ dx)`에 넣으면 tilt 값과 같은지 확인해 보세요.
- **미션**: 각도가 20도를 넘으면 화면에 "TILT!" 띄우기

## 06. AI가 읽은 표정 52가지
- options에 `output_face_blendshapes=True` 한 줄을 추가하면, AI가 표정 점수 52개를 같이 줍니다. 예: `jawOpen`(입 벌림), `eyeBlinkLeft`(왼눈 감김), `mouthSmileLeft`(미소)
- **핵심 비교**: 03·04번에서는 우리가 직접 규칙(높이 ÷ 너비)을 만들었고, 여기서는 AI가 학습해서 판단합니다.
  - 윙크, 실눈, 미소, 입 오므리기를 해 보고 어느 쪽이 더 정확한지 비교하기
  - "미소"는 거리 공식으로 만들기 어렵지만 AI는 알아챕니다. 이게 학습 기반의 힘이에요.

> **07~10은 하나의 계단이에요.** 모두 카메라 창(내 얼굴)과 캐릭터 창(초록 배경)을 따로 띄웁니다.
> 내 얼굴에서는 **숫자만** 가져오고(리모컨), 캐릭터는 자기 그림 안에서 움직여요.

## 07. 내 얼굴 = 리모컨: 캐릭터 그림 전체 돌리기
- 05번의 **기울기**와, 두 눈 사이 거리로 구한 **크기**(03번 비율 아이디어)를 숫자로 뽑습니다.
- 처음 잡힌 얼굴을 **기준**으로 저장해요. 기준보다 몇 도 더 기울었는지, 몇 배 가까워졌는지만 씁니다.
- `getRotationMatrix2D(목, 각도, 배율)`: 목을 중심으로 그림 전체를 돌리고 키우는 변환을 만들고, `warpAffine`으로 적용합니다.
- **관찰 포인트**: 고개를 기울이면 **몸까지 같이** 돌아가요. 입을 벌리고 싶으면? → 그림 전체를 한 번에 움직이는 방식으로는 안 됩니다. 이게 08번으로 가는 질문이에요.

## 08. 메쉬 맛보기: 삼각형으로 쪼개서 입만 벌리기
- 그림 속 점 17개(모서리 4 + 눈, 코, 목, 볼, 턱선, 입, 턱)를 **삼각형으로 잇습니다**(`Subdiv2D` = 들로네 삼각분할). 파란 선이 메쉬예요.
- 입을 벌리면 **아랫입술 점과 턱 점만** 아래로 옮겨요. 그 점에 붙은 삼각형만 늘어나고, 나머지는 그대로입니다.
- `warp_triangle`: 삼각형마다 **원래 꼭짓점 3개 → 옮겨진 꼭짓점 3개** 변환을 구해서(`getAffineTransform`) 그 조각만 늘여 붙입니다.
  - 비유: 그림을 고무판에 붙이고 압정(점)을 꽂았다고 생각하세요. 압정 하나를 옮기면 그 주변 고무만 늘어나요.
- 원본 그림에 입 안이 없으니, 벌어진 곳은 어두운 색으로 칠합니다.
- **미션**
  - `drop * 0.6`(턱이 따라 내려가는 비율)을 0이나 1로 바꿔 보기
  - 코 점을 옮겨 보기

## 09. 내 캐릭터 메쉬 + 점을 돌려서 고개 기울이기
`make_rig.py`(점 찍기 도구)는 **따라 치지 않고 파일로 나눠 줍니다.**

1. 자기 캐릭터 그림을 `my_char/character.png`로 넣기 (투명 배경 PNG 권장, 정면 얼굴)
2. `python make_rig.py my_char/character.png`
   - 터미널에 나오는 순서대로 점 27개를 클릭합니다 (왼쪽/오른쪽은 화면 기준).
   - 다 찍은 뒤 **좌클릭은 머리카락 점**(머리를 따라감), **우클릭은 몸 점**(고정)이에요. 머리카락 끝, 귀 끝 같은 곳에 좌클릭을 몇 개 찍어 두면 고개를 기울일 때 머리카락도 같이 돌아가요.
   - 그림 창을 클릭한 상태에서 `s`를 누르면 `my_char/rig.json`이 저장됩니다.
3. 08을 복사해서 ★ 부분을 칩니다.
   - 08에서 손으로 적었던 점 좌표 대신, `rig.json`의 점 이름(`"chin"`, `"mouth_lower"` 등)으로 메쉬를 만듭니다.
   - **고개 기울이기**: 07은 그림 전체를 돌렸지만, 이번엔 **얼굴·머리카락 점만** 목을 중심으로 돌려요. 그림은 삼각형이 따라 늘어나서 바뀌기 때문에 **몸은 그대로** 있습니다. 07번과 나란히 실행해서 비교해 보세요.
   - 입: 아랫입술 100% > 턱 55% > 턱선 25%로 덜 내려가게 해서 자연스럽게
4. `python 09_my_character.py`

- **AI 이야기**: 이 AI는 만화 얼굴을 못 찾아요 (01번 실험). 그래서 사람이 직접 점을 찍어 줘야 합니다. AI 학습 데이터도 이렇게 사람이 한 장씩 라벨링해서 만들어져요.
  - 같은 그림에 찍어도 학생마다 점 위치가 조금씩 다르죠? 이게 "라벨 품질" 문제예요.
- **보너스**: 이 `rig.json`은 완성 코드와 형식이 같아요. 완성 코드를 받은 뒤 `python main.py --rig my_char/rig.json`으로 실행하면 내 캐릭터가 고급 리깅으로 움직입니다.

## 10. 완성판: 메쉬 변형 버튜버 (읽기용)
따라 치기엔 길어서(약 250줄) **파일로 나눠 주고 같이 읽는** 단계예요. 완성 코드(`main.py`)와 같은 원리를 파일 하나에 담았습니다. `w` 키를 누르면 메쉬가 보여요.

**동작 순서**
1. **캐릭터 불러오기**: `rig.json`(09번)과 그림을 읽고, 머리가 움직일 공간으로 둘레에 투명 여백을 붙입니다.
2. **메쉬 만들기**: 점 27개 + 눈·입 둘레 보조점 + 머리카락 점 + 그림 가장자리 고정점을 **삼각형으로 잇습니다**(들로네 삼각분할).
   - 점마다 `follow`(머리를 따라가는 정도)와 `depth`(고개 돌릴 때 움직이는 양)가 있어요.
3. **내 얼굴 → 숫자**: 처음 얼굴을 기준으로 기울기, 크기, 위치, 좌우·상하 돌림, 눈썹, 입 벌림, 미소, 눈 감김을 구합니다. `soft()`로 떨림을 줄여요.
4. **숫자 → 점 이동** (`deform`)
   - 눈썹 점: 위아래로
   - 입 벌림: 아랫입술 100%, 턱 55%, 턱선 25%만 내려감
   - 미소: 입꼬리가 위·바깥으로
   - 고개 좌우·상하: 점마다 `depth`만큼 이동 → 코·눈이 윤곽보다 많이 움직여 **입체감**
   - 기울기·크기·위치: **목**을 중심으로, `follow`만큼만 (몸은 고정)
5. **삼각형마다 그림 늘여 붙이기** (`warp_triangle`): 08·09번과 같은 3점 → 3점 변환을 삼각형 134개에 각각 적용
6. **덧그리기**: 눈꺼풀(뜬 정도만큼 위아래에서 덮어 옴), 입 안 + 혀

**07~09와 비교**

| | 07~09 | 10 |
|---|---|---|
| 메쉬 | 07 없음, 08·09 점 17~40개 | 점 76개 + 눈·입 둘레 보조점 |
| 입 | 턱이 내려가고 입 안은 사각형으로 칠함 | 입 안을 입술 곡선 모양으로 + 혀 |
| 눈 | 없음 | 뜬 정도 0~1만큼 눈꺼풀이 점점 (AI 점수) |
| 눈썹·미소·입체감 | 없음 | 있음 |
| 기준 얼굴 | 있음 (07·09) | 있음 + `c` 키로 다시 잡기 |
| 떨림 줄이기 | 없음 | 있음 (`soft`) |

- **질문거리**: "09번에 무엇을 더하면 이렇게 될까?" → `w` 키로 메쉬를 보여 주며 09번과 비교하세요. 새로 더해진 건 `depth`(입체감), 눈썹·미소, 눈꺼풀, 떨림 줄이기예요.
- 거울 화면이라 AI의 `eyeBlinkRight`가 **화면 왼쪽** 눈이에요.
- **미션**
  - `soft`의 `keep` 값을 0.9 / 0.0으로 바꿔 보기 (부드러움 ↔ 반응 속도)
  - `deform` 안의 숫자 바꿔 보기 (턱 `0.55`, 입체감 `0.14`, 눈썹 `0.45`)
  - `WEIGHT` 표의 `depth`를 바꿔 입체감이 어떻게 달라지는지 보기
  - 배경색 `BG` 바꾸기

## 끝나고 나눠 줄 완성 코드
